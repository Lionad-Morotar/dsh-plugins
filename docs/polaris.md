# 北极星目标（Polaris）

> 本文件定义项目的长期愿景。北极星循环据此发散性创造 epic，跃进式选择开发方向。

## 工作台三件套（文件 / Git / 终端）

* 愿景描述：把 DSH 的会话窗口补成一个可长期工作的 IDE 级工作台。文件插件提供虚拟化目录树、git 状态着色、语法制导预览与多面板编辑区；Git 插件提供左变更右历史图的常驻并排视图与跨插件跳转；终端插件在页面底部提供可全屏、可分割、可最小化的 dock。三者共用一套命令与键盘模型，做到全键盘可达且与宿主既有插件无冲突。
* 验收信号：三个插件可在 web profile 正常安装挂载；文件树 git 状态与 `git status --porcelain=v2` 逐条一致；3000 commit 的 Git 图首屏 < 500ms；终端面板与进程 1:1 且切视图后输出连续；全部可见操作可用键盘完成，Esc 在无弹窗时 100% 回到对话；每包启动产物 < 60KB gzip。
* 优先级：高

## 宿主契约适配层

* 愿景描述：把与宿主内部 seam 的接触面（槽位、Remote 服务、终端视图、快捷键协议、composer-overlay 行为）收进薄适配层，使宿主版本升级时只改一处，并把每一处接触面写成可回归的验证脚本。
* 验收信号：新增一个适配层包且被三件套依赖；宿主升 rc 版本时，全部适配层回归脚本可在一次运行内给出绿/红结论；三件套代码中不出现直接用宿主席位字符串以外的内部路径引用。
* 优先级：中

## 插件分发与市场索引

* 愿景描述：让自研插件具备可分发形态：市场索引产物、readme 与安装说明、版本与变更记录同源生成，减少手工同步。
* 验收信号：`pnpm build:market` 与 `check:market-index` 在新增插件后仍全绿；每个可分发插件都有 README 与 icon；清单检查器对 private 与 public 包的断言不退化。
* 优先级：中
